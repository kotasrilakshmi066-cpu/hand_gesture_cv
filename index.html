VirtualMouse.CV
Academic CV Project v1.0

Hand Gesture Controlled Virtual Mouse

A real-time Computer Vision Human-Computer Interface (HCI) leveraging Google MediaPipe Hands, OpenCV, and PyAutoGUI to control computer cursors via contactless hand movements.

View GitHub Repository Local Execution Guide

Core Gesture Controls

Geometric classification based on Euclidean distance across 21 hand landmarks

☝️

Cursor Navigation

Index fingertip (Landmark 8) controls screen position with Exponential Moving Average (EMA) smoothing and noise deadband suppression.

🤏

Left Click

Pinch gesture between Thumb Tip (4) and Index Tip (8) with Euclidean distance < 35px. Fully debounced to prevent duplicate clicks.

👌

Right Click

Pinch gesture between Thumb Tip (4) and Middle Tip (12) (< 38px) while Index is extended away. Triggers context menus.

✌️

Dual-Finger Scroll

Raise both Index and Middle fingers together. Moving hand vertically up or down scrolls documents and web pages fluidly.

✋

Neutral / Rest Mode

Open hand palm or closed fist safely suspends all mouse action dispatches without halting the camera stream.

🛑

Safety Failsafe

Moving cursor to any monitor corner or clicking Emergency Stop immediately aborts PyAutoGUI hardware dispatching.

How to Run Locally on Your Laptop

Because virtual mouse control requires direct access to your physical webcam and OS cursor, execute locally on Windows/macOS/Linux:

# 1. Clone the repository
git clone https://github.com/kotasrilakshmi066-cpu/hand_gesture_cv.git
cd hand_gesture_cv

# 2. Install dependencies (Python 3.10 or 3.11 recommended)
pip install -r hand_gesture_virtual_mouse/requirements.txt

# 3. Launch application
run.bat
# OR: python hand_gesture_virtual_mouse/main.py
